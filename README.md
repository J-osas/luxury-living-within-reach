# Luxury Living, Within Reach

A sketch of a fictional UK home concept. The pages present three design-led homes and an illustrative monthly picture of owning and running one. The homes are not for sale. The working title is not a finished brand name.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run build` produces the production build.

## What is here

- Home, with the concept in one screen and three homes in the same slots
- A home page for each role, with the cost panel inside the story
- Compare, Approach, Costs and Energy, and a three-step feedback form

Feedback is saved in the browser only. It is not sent anywhere.

## What is unfinished

The name, logo, palette, and type are provisional. Image frames are empty on purpose. There is no virtual host, no social campaign, no accounts, and no mortgage calculator.
